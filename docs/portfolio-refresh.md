# Portfolio refresh

The portfolio is a responsive static site in `index.html`. Project cards open accessible detail dialogs with product purpose, organization/client, role, technologies and outcomes. Where older portfolio entries lacked supporting details, the dialog says so instead of inventing a client, stack or metric.

## Profile and toolkit

The profile now describes Rajabu's entrepreneurial approach to software: identifying a practical user or business problem, shaping a product around it and carrying the work through delivery. The skills section includes Python, Django, PHP/Laravel, JavaScript, React, TypeScript, Dart/Flutter, Node.js, REST APIs, Tailwind CSS, Bootstrap, SQL/PostgreSQL, Docker, CI/CD, Git, Linux, NGINX, VPS deployment, release workflows, production support and engineering tooling.

TanzMED is the only project whose supplied project-specific stack is listed as Laravel for the backend, Flutter for the mobile app, Dart and Docker. The other project dialogs continue to identify technology as unavailable where the sources do not support a stack claim.

## Site files

- `index.html` — content, project cards and accessible project dialog
- `assets/css/portfolio.css` — responsive visual design and dialog styles
- `assets/js/portfolio.js` — mobile navigation, project content and dialog behavior

Open `index.html` in a browser or serve the repository root as a static site. No build step is required. Google Fonts and project photos load remotely.
