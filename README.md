# Rajabu Mrisho — Portfolio

A responsive, static portfolio for Rajabu Mrisho. The page highlights professional experience, software projects across several industries, technical skills and contact links. Project cards open case-study dialogs with client, role, technology and outcome details.

## Preview

Open `index.html` directly in a browser or serve the repository root with any static web server. No package installation or build step is required. Google Fonts are loaded remotely; the rest of the site uses local assets.

## Files

- `index.html` — portfolio content
- `assets/css/portfolio.css` — site styles and responsive layout
- `assets/js/portfolio.js` — mobile menu, case-study dialogs and footer year
- `docs/portfolio-refresh.md` — content and project summary
